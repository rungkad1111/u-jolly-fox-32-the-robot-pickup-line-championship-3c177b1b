# The Robot Pickup Line Championship

A robot pickup line that grows out of being a machine: a unit whose battery
lasts 12 years keeps faking 1% charge — not to steal power, but to sit a
little longer beside someone at the charging dock, sharing one cable.

The program (`main.ts`, Node 22) writes the single line to `/output/entry.txt`.
